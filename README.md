# ALCHEMIK

ALCHEMIK to profesjonalna platforma do analizy rynku akcji, ze szczególnym naciskiem na spółki typu Penny Stocks (groszówki).

## Struktura projektu

Projekt jest zbudowany w sposób modularny, co umożliwia łatwą rozbudowę i niezależne rozwijanie każdego modułu.

### Główne cechy:
- Modularność
- Czytelność kodu
- Łatwość rozbudowy
- Stabilność

## Moduły

Wszystkie moduły są opisane w odpowiednich plikach w katalogach projektu.
